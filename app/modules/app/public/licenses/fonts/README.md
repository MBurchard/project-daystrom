# Bundled fonts

Project Daystrom bundles the web-font subsets of Inter and Rajdhani locally. No font is loaded from a
third-party service at runtime. Inter ships as two files, the Latin subset and a small symbol subset
that covers the status indicators the Latin range omits (U+D7, U+21BB, U+2713, U+2717).

- Inter is distributed under the SIL Open Font License 1.1. The licence text is included in
  `Inter-OFL.txt`. Source: <https://github.com/google/fonts/tree/main/ofl/inter>
- Rajdhani is distributed under the SIL Open Font License 1.1. The licence text is included in
  `Rajdhani-OFL.txt`. Source: <https://github.com/google/fonts/tree/main/ofl/rajdhani>
